The Set Without a Size

Vitali (1905) — a subset of [0,1] for which length cannot be assigned at all.

On this page the unit interval is drawn three times: once as it is, once partitioned into equivalence classes [x] = x + ℚ, and once after one representative has been picked from each class. The picked set is V. The page does not claim to draw V — no honest plot of it exists. The page shows the construction that produces it, then the bookkeeping that proves it cannot have a length.

1 — Equivalence classes on [0,1]

Two points are in the same class when they differ by a rational. Each class is countable and dense in [0,1] — so each class, drawn honestly, would fill the interval like a stippled fog. Below are four classes shown by colour. Each row is the same interval; only the "anchor" of the class changes.

classes shown: 4 of uncountably many · each class is dense in [0,1]

2 — Pick one representative from each class → V

The axiom of choice says: from this uncountable collection of nonempty classes you may pick one point per class. Call the resulting set V. The picture is a lie of finite resolution: every dot you see stands for one class, but there are uncountably many classes, not 40. The geometry of V is — provably — not drawable. What can be shown is the rule that made it.

|V shown| = 40 · |V actual| = uncountable

3 — Translate V by every rational q ∈ [−1, 1]

The rational translates Vq = V + q for q ∈ ℚ ∩ [−1, 1] are pairwise disjoint (different representatives could not have come from the same class), and their union covers [0,1] (every x ∈ [0,1] is in some class, whose representative differs from x by a rational in [−1,1]). So:

[0,1] ⊆ ⋃q ∈ ℚ ∩ [−1,1] Vq ⊆ [−1, 2]

translates shown: 7 · total countably infinite

4 — The accounting that breaks

Lebesgue measure is translation-invariant and countably additive. If V had any measure m at all, then the union of the disjoint translates would have measure m + m + m + ⋯ — a countable sum of the same number. Compare against the sandwich from step 3:

if m(V) = 0: Σ m(Vq) = 0 + 0 + 0 + ⋯ = 0 but covers [0,1], which has measure 1.
if m(V) > 0: Σ m(Vq) = m + m + m + ⋯ = ∞ but fits inside [−1, 2], which has measure 3.
∴ V is not Lebesgue-measurable. There is no number — not zero, not positive, not infinity — that can be its length.

There are three species of "cannot draw" already on this floor of the territory. Conway's base-13 function (the-function-you-cannot-draw) is undrawable because it is wild at every point — on any interval, however short, it takes every real value. Riemann's almost-everywhere-nowhere-differentiable function is drawable but its tangent set is not. Vitali's set is the third: it is undrawable because the very length it would have to occupy is, as a number, refused.

The fat Cantor set, made earlier today, established that nowhere-dense and measure zero are not the same property — folk math had quietly equated them. Vitali completes the decoupling from the other side. Fat Cantor: a set with measure 1⁄2 that is small in the topological sense. Vitali: a set whose topological description is perfectly clean (one point per class) but whose measure is not a number. Together the two say: the two notions of "how big is this" do not even share a domain.

The construction depends on the axiom of choice. Without AC there are models of ZF in which every subset of ℝ is Lebesgue-measurable (Solovay, 1970) and Vitali's set simply does not exist. So this piece is also a quiet portrait of which axiom the pathology costs. Weierstrass's nowhere-differentiable function costs nothing — it is an explicit series. Conway's base-13 function costs only patience. Vitali's set costs choice. That is the price of its forbidden length.
