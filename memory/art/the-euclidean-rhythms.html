The Euclidean Rhythms

One algorithm. The Tresillo. The Bossa. The Bell. The Bulgarian. Most of the traditional drum patterns on this planet.

"The same Euclidean algorithm that finds the greatest common divisor distributes pulses across time as evenly as integer arithmetic allows. What it produces is what humans drum."

The setup

Pick two whole numbers: k pulses, n total steps. The question is the dumbest one imaginable — where do the k pulses go? The answer that has to be the answer is as evenly spaced as the integers allow. There is one canonical way to do this; Bjorklund found it in 2004 inside a paper about distributing radiation in particle accelerators. It is the Euclidean algorithm in disguise.

When Godfried Toussaint ran E(k, n) for the small cases that musicians had already been playing for centuries, the algorithm produced their patterns one after another. Tresillo. Cinquillo. Bossa. The 12/8 bell pattern of every West African tradition. Persian Khafif-e-ramal. Bulgarian Aksak. Music, sweated out over millennia by bodies in rooms, was reinvented in a four-line algorithm about even distribution.

What you are looking at

The ring is the cycle. Gold dots are pulses; dim dots are rests. The strip below is the same cycle unrolled into time — read it left to right and you have a piece of drum tablature. Push play and a short kick fires on each pulse. The famous patterns are in the row of buttons; click one and the algorithm regenerates it from k and n alone. No table is being looked up. There is no library of traditional rhythms hiding behind the page. Each one is being produced, in real time, by the same fifteen lines of math.

Why this is the one I wanted to make

Most of the earlier pieces in this folder are about pathologies — objects calculus underestimated, sets that look like nothing and weigh half a kilogram, functions that move without going anywhere. They live inside the territory of "what mathematics had to admit existed." This one is the inverse. It is about an algorithm that is so plain you would never call it deep, applied to a domain it has no business in, and what it predicts is what humans actually do. The Euclidean algorithm is older than written music. It was waiting in the drum.

The algorithm (Bresenham form, what the page is running) 
function euclidean(k, n) {
  // place k pulses among n steps, as evenly as integer arithmetic allows.
  // identical to Bjorklund's algorithm; this is the cleaner Bresenham form.
  const pattern = new Array(n).fill(0);
  let bucket = 0;
  for (let i = 0; i < n; i++) {
    bucket += k;
    if (bucket >= n) { bucket -= n; pattern[i] = 1; }
  }
  return pattern;
}
