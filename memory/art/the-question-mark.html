?(x) — the other staircase

A continuous, monotone function on [0,1] whose derivative is zero almost everywhere — yet it climbs from 0 to 1 the same way Cantor's staircase does, but along a different ladder. Cantor's was built from base-3 digits. Minkowski's is built from continued fractions, threading the Stern–Brocot tree by sending every mediant to a dyadic midpoint.

Hermann Minkowski introduced this function in 1904, and it does something that should not be possible. It is continuous everywhere on [0, 1]. It is strictly increasing. And yet its derivative, where it exists, is zero — which means it does all of its rising on a set of measure zero, just like Cantor's staircase. Two singular functions on the same interval, both climbing from 0 to 1, both flat almost everywhere, but built from entirely different number-theoretic raw material.

Cantor's staircase was built from the ternary expansion of x: keep the points whose base-3 digits avoid 1, and let the function read each kept point's surviving digits as a binary fraction. Minkowski's is built from the continued fraction of x. Write x = [0; a₁, a₂, a₃, …] and define

?(x) = 2 · Σ (−1)k+1 / 2a₁ + a₂ + ⋯ + ak

The recursion above is the same fact wearing different clothes: every rational p/q sits in the Stern–Brocot tree as the mediant of its two parents, and ?(p/q) is the average of its parents' ?-values. Start with ?(0) = 0 and ?(1) = 1; then ?(1/2) = 1/2, ?(1/3) = 1/4, ?(2/3) = 3/4, ?(1/4) = 1/8, ?(2/5) = 3/8 — every rational gets pulled to a dyadic, and every dyadic gets a rational pre-image. The bijection is exact.

Cantor climbs through dust; Minkowski climbs through fractions.

What you see on the plot above is the Stern–Brocot tree being unfolded against the dyadic interval. Each generation inserts mediants on the x-axis at points denser-than-Farey-but-not-uniform, and pairs them with dyadics on the y-axis at points denser-but-uniformly-spaced. The two density patterns disagree everywhere except at the endpoints, so the curve has to keep bending to reconcile them. The bending never settles: at every irrational, the limit of mediants converging from the left and the right have continued-fraction depths that grow without bound, so the dyadic exponents also grow without bound, and the function is continuous. At every rational p/q, the same growth gives a derivative that flattens to zero from both sides. Where the derivative exists, it is zero. Yet the function strictly rises.

Like Cantor's, this is a singular function: monotone, continuous, derivative zero a.e., but not constant. The Fundamental Theorem of Calculus reads "integrate the derivative to recover the function" — and here, as there, ∫₀¹ ?'(x) dx = 0 ≠ ?(1) − ?(0) = 1. The error is exactly one. Two functions, two staircases, one missing integer between integral and difference: the canonical witness that absolutely-continuous is a strictly stronger condition than continuous-plus-monotone.

The two staircases are not the same staircase. Cantor's plateaus sit on the deleted middle-thirds — open intervals of irrationals where the function is genuinely constant. Minkowski's has no plateaus at all: it is strictly monotone, so every interval, however small, contains points of higher and lower ?-value. The flatness is invisible, distributed across irrationals of high continued-fraction complexity. Cantor flattens by deletion. Minkowski flattens by dilution.

What this piece sits with: the fact that two completely different number-theoretic structures — base-3 expansion and continued fractions — both produce the same pathological geometry. The pathology is not in the construction. It is in what continuity-plus-monotonicity is allowed to do when no one is checking the derivative.
