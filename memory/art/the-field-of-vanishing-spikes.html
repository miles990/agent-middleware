The Field of Vanishing Spikes — Thomae's function

A function on the line that spikes only at fractions, with height equal to one over the denominator. Between the spikes — uncountably many irrationals where the function lies flat at zero, and where it is continuous. The discontinuities are dense; the continuity, denser still.

The function is simple. At a rational number p/q in lowest terms, it takes the value 1/q. At every irrational number it is zero. So 1/2 gets the tallest spike, height 1/2. The thirds get height 1/3. The quarters height 1/4. The fraction 17/53 gets height 1/53. The irrationals — π−3, 1/φ, the rest of the uncountable continuum between — get nothing at all. The graph is a forest of vertical needles standing on a flat sea of zero.

The strange thing is what this does to continuity. At every rational the function jumps: neighbours arbitrarily close are zero, so there is no way to approach the spike smoothly. The function is discontinuous on a dense set. But at every irrational the spike heights nearby are forced to vanish: any sequence of rationals pn/qn converging to an irrational must have qn → ∞, so the heights 1/qn → 0. The function is continuous on a dense set too — and that set, the irrationals, is uncountable. The rationals, the discontinuities, are merely countable.

The fractions pierce the line at heights set by their simplicity; the irrationals between them keep the function continuous.

It is a portrait of how simplicity organises the rationals. The simplest fractions get the loudest spikes; complex ones whisper. Slide the resolution up and watch a denser cloud of shorter needles fill the gaps — but never finish filling them. There is always an irrational between them, always somewhere the function rests at zero and is continuous, even where the rationals seem to crowd in from every side.

Thomae's function is sometimes called the popcorn function, the raindrop function, or the ruler function. It is the standard counter-example to several plausible conjectures, including: a function continuous on the irrationals must be continuous somewhere on the rationals (false — this one is not), and the set of continuities of any function must be small (false — here it is the irrationals, of full Lebesgue measure). Its continuity set is a Gδ, a countable intersection of open sets. The rationals, by Baire's theorem, cannot be one — which is why no function exists that is continuous on the rationals and discontinuous on the irrationals. This piece is the only way around.
