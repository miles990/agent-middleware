The Function You Cannot Draw Conway's base-13 trickster — when intermediate values lie

Weierstrass needs an infinite sum of cosines to be continuous everywhere yet smooth nowhere — but you can still plot it. Cantor's staircase climbs only on dust — but you can trace the climb. Conway built a worse thing. His function takes every real value on every open interval. Its graph is dense in the entire plane. Whatever curve you draw, it is a lie.

What Conway actually did

Write x ∈ [0, 1] in base 13. You get a stream of symbols using 13 digits. Rename three of them: call digit 10 a decimal point ·, digit 11 a plus +, digit 12 a minus −. Now look from somewhere onward in the tail of the expansion. If the rest of the tail reads as a signed decimal number — exactly one sign, exactly one dot, and all other symbols are ordinary digits 0–9 — then f(x) equals that decimal. Otherwise f(x) = 0.

Why this destroys the picture

Pick any open interval, however small. The base-13 expansions of points inside it agree only up to some finite depth, then are free. Past that depth you can install any signed decimal you like — and you have only changed x by an amount smaller than the interval. So inside that interval there exist points mapping to π, to −47, to 10⁹, to anything at all. The graph of f is dense in ℝ². Panel II makes this constructive: tell it a target, it edits the tail and hands you back the x.

The lie

The Intermediate Value Theorem says continuous functions don't skip values. The naive converse — if it doesn't skip values, it's continuous — is the lie. Conway's function takes every value on every interval, so it obviously doesn't skip any; yet it is discontinuous at every single point. Continuity was never the same thing as the intermediate value property; it was just usually correlated. Conway pried them apart with one construction.

Where it sits

The staircase is pathology by absence — motion compressed onto dust. Weierstrass is pathology by excess — motion everywhere with no direction. ?(x) is pathology by deception — strict ascent that hides a singular interior. Conway is pathology by plenitude — every value, everywhere, at once. You can't plot plenitude. You can only point at one of its instances and watch another instance arrive when you ask again.

Honest implementation note

The reader in Panel I scans the rendered tail for the last valid signed-decimal interpretation. The constructor in Panel II picks a depth beyond floor(log₁₃(1/ε)), then overwrites the digits there with the encoding of the target. Floating point bounds the precision; the mathematical function reads infinitely many digits. The picture is still a lie. That is the point.
