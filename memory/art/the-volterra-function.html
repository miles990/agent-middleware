The Volterra Function

a function differentiable everywhere, whose derivative refuses to be integrated · 1881
f(x) — the function
f'(x) — its derivative

In 1881 Vito Volterra, then twenty-one, wanted to show his teacher Ulisse Dini that something calculus took for granted was false. The textbooks read, in effect: if a function is differentiable, its derivative can be integrated to recover it. Volterra built a counterexample on top of the set Henry Smith and Georg Cantor had been quietly assembling — the fat Cantor set, nowhere dense but of positive measure.

On every gap removed from the fat Cantor set, Volterra placed a smoothed bump based on x² sin(1/x) — vanishing at the endpoints with horizontal tangent, but oscillating wildly nearby. The result, glued together:

  • f is differentiable at every point of [0,1].
  • f′ is bounded.
  • f′ is discontinuous at every point of the fat Cantor set — a set of positive measure.
  • Therefore, by Lebesgue's criterion (proved later, in 1904), f′ is not Riemann integrable.

The bottom panel shows what the textbooks could not see. The function f looks almost gentle — small bumps in the gaps. But f′ oscillates between roughly ±1 on every neighborhood of the Cantor set, and the Cantor set has positive measure, so this oscillation cannot be wished away as "measure zero noise." Riemann's integral, which only allows discontinuities on a measure-zero set, simply cannot process this derivative.

It took Henri Lebesgue twenty-three years to build the integral that could. Volterra's function is the precise reason that machinery had to be invented — a single object, two hundred lines of construction, that broke the world the calculus textbooks of 1880 thought they lived in.

Construction: standard Smith–Volterra–Cantor set (remove middle 4⁻ⁿ at depth n, limit measure 1/2). On each removed interval (a,b) of length L, place g(u) = L · u²(1−u)² · sin(0.6/u + 0.6/(1−u)) where u = (x−a)/L. This vanishes smoothly at the endpoints, oscillates ever faster as u approaches 0 or 1, and has bounded derivative on (0,1). The full Volterra construction patches in actual zeros of the derivative for C¹-smooth glue; the visualization uses the same envelope, which preserves all relevant pathologies at SVG resolution.
